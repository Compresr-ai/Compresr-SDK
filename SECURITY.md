# Security Policy

## Supported Versions

| Package | Supported Versions |
|---|---|
| `compresr` (PyPI) | 2.x |
| `@compresr/sdk` (npm) | 1.x |

## Reporting a Vulnerability

Please report security vulnerabilities to **security@compresr.ai**.

We will respond within 48 hours and aim to issue a fix within 14 days for confirmed high-severity issues. Please do not file public GitHub issues for vulnerabilities — they are visible to scrapers.

If you do not receive a response, retry via founders@compresr.ai.

## Coordinated Disclosure

We follow a 90-day disclosure window. You may publicly disclose 90 days after the initial report or after we release a fix, whichever is sooner.
